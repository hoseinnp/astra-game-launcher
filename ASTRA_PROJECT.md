# Astra Game Launcher

**Version:** 1.0.0  
**Status:** Current Release  
**GitHub:** https://github.com/[USERNAME]/astra-game-launcher

## Core Features
- 3D Physical Shelf & Cartridge Inspector
- Save Game Vault & Auto-Backup
- Retro Hub & Emulation Center
- Mod Manager (Astra Armory)
- Astra Jukebox & Audio Visualizer
- Activity Heatmap
- In-Game Mini-HUD
- Game Oracle (AI Lore & Strategy Co-Pilot)

## Tech Stack
- Frontend: React 19 + TypeScript + Vite
- Backend: Electron + Node.js
- Audio: Web Audio API with reactive visualizer
