# ASTRA Launcher — Evolution Roadmap

## 🚀 Version 3.0 Backlog (Locked In)

These features have been selected and queued for the **v3.0 major release**:

1. **🛡️ Save Game Vault & Auto-Backup**
   - Automatic detection of save folders across `%APPDATA%`, `Documents/My Games`, and `Saved Games`.
   - 1-click zipped point-in-time snapshots and rolling backups before game launch.
   - Corrupt save protection, quick-restore points, and export/import functionality.

2. **🎵 Astra Jukebox & Audio Visualizer**
   - Dedicated OST & ambient sound studio inside the launcher.
   - Reactive audio waveform spectrum and frequency visualizers matching game vibe color palettes.
   - Lo-fi radio mode, custom playlist queuing, and smooth volume ducking during game launch.

3. **📊 Gaming Activity & Playtime Heatmap**
   - GitHub-style annual & monthly activity contribution matrix / calendar.
   - Deep session logging: start/end times, session durations, daily play distribution.
   - Peak gaming hour analytics and automated milestones (e.g. *100-Hour Club*, *Weekend Warrior*).

4. **⚡ In-Game Companion Mini-HUD**
   - Lightweight, hardware-accelerated transparent overlay accessible via global hotkey (`Shift + Tab` or Xbox Guide button).
   - Fast access to game strategy notes, checklists, real-time clock, screenshot captures, and volume controls without alt-tabbing.

5. **🕹️ Retro & Emulation Hub**
   - Seamless ROM directory scanner and bios validation.
   - 1-click launcher integration for popular emulators (*RetroArch*, *Dolphin*, *PCSX2*, *RPCS3*, *DuckStation*).
   - Retro box-art scraping, bezel matching, and custom emulator launch arguments.

6. **🤖 Astra Game Oracle (AI Lore & Strategy Co-Pilot)**
   - In-launcher tactical assistant inside the Intel Deck for spoiler-free quest guidance, boss weaknesses, character builds, and lore summaries.
   - Context-aware prompt templates tailored to each game universe without alt-tabbing.

7. **📦 3D Physical Game Shelf & Cartridge Inspector**
   - Interactive 3D virtual shelf and game room with customizable lighting.
   - Realistic 3D physical game cases, retro cartridges, and steelbooks that you can rotate 360°, open, and inspect with glossy reflection shaders.

8. **⚔️ Mod & Add-on Deck (Astra Armory)**
   - Integrated mod directory scanner, mod order manager, and 1-click active/inactive toggles.
   - Compatibility with script extenders and loaders (*SKSE*, *F4SE*, *Cyber Engine Tweaks*, *REFramework*).
   - Mod profile presets (e.g., *Vanilla+*, *Graphical Overhaul*, *Hardcore*) and conflict warnings.
